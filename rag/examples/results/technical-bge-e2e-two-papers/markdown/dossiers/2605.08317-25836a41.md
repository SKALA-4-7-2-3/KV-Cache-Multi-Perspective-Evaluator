### 초록

Large language models (LLMs) have shown strong performance across diverse
tasks, but their inference with long input contexts is bottlenecked by memory size
and bandwidth. The Key-Value (KV) cache size grows linearly with sequence
length and needs to be re-read from off-chip high-bandwidth memory (HBM) to
on-chip memory at every decoding step, resulting in memory-bound inference.
Existing methods reduce the cache by either eviction or quantization, but typically
treat the two in isolation. In this paper, we cast KV cache compression as a rate-
distortion problem, under which eviction and quantization are two end-points of
the same bit allocation scheme. This exposes the need to optimize them jointly,
motivating our method, RDKV (Rate-Distortion KV cache compression). RDKV
derives the weight of each token or channel from the distortion that compression
induces on the attention computation. Based on these weights, it assigns each token
or channel a bit-width ranging from full precision down to zero bits guided by
reverse water-filling, applied once after the prefilling stage. Experiments on Long-
Bench, RULER, and InfiniteBench show that RDKV outperforms the best evaluated
baseline by 9.1% on average. On LongBench it recovers 97.81% of full-cache accu-
racy with only 2.48% cache retention. Compared with full-cache FlashAttention-2
decoding, it achieves 4.5× decode speedup and 1.9× peak memory reduction with
128K context length, while maintaining comparable performance.

## 기술 개요

### 문제 정의

- 장문맥 LLM 추론에서는 KV cache가 시퀀스 길이에 선형으로 증가하고, 매 decoding step마다 off-chip HBM에서 on-chip memory로 재읽혀 memory-bound inference가 된다.
  - `author_claim` · confidence `0.990` · [ev-005](../evidence_registry.md#ev-005)
- 기존 KV cache 축소 방법은 eviction 또는 quantization을 대체로 분리해 다루며, 논문은 양자를 공동 최적화할 필요가 있다고 제시한다.
  - `author_claim` · confidence `0.980` · [ev-005](../evidence_registry.md#ev-005)

### 핵심 접근법

- RDKV는 고정 bit budget에서 V cache의 token과 K cache의 channel에 bit-width를 할당해 weighted distortion을 최소화하는 rate–distortion KV cache compression 방법이다.
  - `author_claim` · confidence `0.990` · [ev-002](../evidence_registry.md#ev-002)
- 이 방법은 layer-head별로 prefill 후 한 번 실행되며, FP16 reference에서 per-head budget을 V와 K에 동일하게 BV=BK=1/2 Bhead로 분할한다.
  - `author_claim` · confidence `0.980` · [ev-017](../evidence_registry.md#ev-017)

### 신규성

- RDKV는 eviction을 zero-bit, quantization을 finite-bit로 동일 allocation curve의 양 끝점으로 모델링하고, 두 동작을 staged 방식이 아니라 단일 solver에서 함께 선택한다.
  - `author_claim` · confidence `0.000` · [ev-002](../evidence_registry.md#ev-002)

### 메커니즘·알고리즘·수식

- V token weight는 wt=Στaτ,t이고, K channel weight는 wc=||Q:,c||||K:,c||/√d이다.
  - `author_claim` · confidence `0.990` · [ev-027](../evidence_registry.md#ev-027)
- V-side MCKP는 calibrated εV(b)와 token weight로 bVt∈{0,2,4,8,16}을 할당하며, bVt=0인 token은 eviction되고 bVt&gt;0인 token은 Tkept에 남는다.
  - `author_claim` · confidence `0.990` · [ev-017](../evidence_registry.md#ev-017)
- K-side MCKP는 Tkept에 대해서만 channel별 bKc∈{0,2,4,8,16}을 독립 할당하고, bKc=0은 zero-rate 제거를 뜻한다.
  - `author_claim` · confidence `0.990` · [ev-017](../evidence_registry.md#ev-017)
- Lagrangian-bisection MCKP solver는 각 unit에 대해 b*ν=arg minb∈B[wνε(b)+λb]를 고르고, |b̄cur−b̄|/b̄&lt;δ이면 할당을 반환하며 그렇지 않으면 λ를 갱신한다.
  - `author_claim` · confidence `0.990` · [ev-010](../evidence_registry.md#ev-010)
- TriZone packing은 V token을 bit-width별 S2·S4·S8 sub-segment로 정렬해 byte-pack하고, Tkept의 K rows를 byte-pack하며, 16-bit V rows는 FP16 Zone B에 저장한다.
  - `author_claim` · confidence `0.990` · [ev-001](../evidence_registry.md#ev-001)
- TriZone은 dequantization을 attention kernel에 fuse하는 packed-decode layout으로 제시된다.
  - `author_claim` · confidence `0.980` · [ev-002](../evidence_registry.md#ev-002)

### 학습 과정

- RDKV는 model weights 또는 training procedures를 수정하지 않는 inference acceleration 기법으로 설명된다.
  - `author_claim` · confidence `0.980` · [ev-003](../evidence_registry.md#ev-003)

### 추론 과정

- Algorithm 1의 입력은 layer별 prefill KV cache, per-head budget, observation-window size, pooling kernel, bit-width set B={0,2,4,8,16}, empirical distortion tables εK(b)·εV(b)이고, 출력은 각 layer-head의 TriZone packed cache이다.
  - `author_claim` · confidence `0.990` · [ev-001](../evidence_registry.md#ev-001)

### 입력·출력·데이터·연산 요구사항

- 이산 allocation은 bit-width set B={0,2,4,8,16}과 empirical distortion tables εK(b), εV(b)를 입력으로 사용한다.

- RDKV는 prefill 직후 KV cache를 한 번만 압축하고 decoding 중에는 재평가하지 않으므로, generation 중 발생할 수 있는 attention-pattern shift에 대해 allocation이 고정된다.

- 저자들은 decode phase로의 확장을 future work로 제시하며, 최근 decode token의 attention weight를 작은 buffer에 누적하고 주기적으로 동일한 MCKP allocation을 적용하는 방식을 제안한다.
