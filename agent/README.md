# 평가·종합 에이전트

이 폴더에는 **4개 에이전트**가 있습니다. 논문을 읽는 [RAG](../rag/README.md)와 최종 PDF를 만드는 [Report](../report/README.md)는 별도 모듈입니다.

| 폴더 | 역할 | 주요 입력 | 전달하는 내용 |
| --- | --- | --- | --- |
| [domain](domain/README.md) | 도메인 적합성 | 논문 근거·요청·운영 요구조건 | 데이터센터 적용 조건·효과·제약 |
| [market](market/README.md) | 시장성 | 논문 근거·요청·웹 자료 | 관련 제품·생태계·사업적 맥락과 출처 |
| [stakeholder](stakeholder/README.md) | 이해관계자 | 논문 근거·요청·웹 자료 | 운영 조직의 기대 이익·부담·도입 조건 |
| [review](review/README.md) | 종합 | 세 관점의 평가·논문 근거·웹 자료 | 관점 간 연결·조건부 의견·미확인 사항 |

세 관점은 같은 요청을 기준으로 분석합니다. 현재 실행 순서는 domain → stakeholder → market → review이며, 전체 실행과 입력 형식 연결은 루트 `pipeline/`에서 담당합니다.

통합 실행은 저장소 루트에서 Python 3.12 환경을 사용합니다.

```bash
uv sync --frozen
uv run --frozen python -m pipeline
```

각 하위 README의 명령은 해당 모듈을 독립적으로 실행하는 안내입니다. 통합 사용자는 [루트 실행 안내](../README.md)와 [상세 파이프라인 안내](../docs/pipeline.md)를 기준으로 실행하면 됩니다.

수집 자료는 검토에서 채택되지 않았다는 이유만으로 삭제하지 않습니다. 실제 내용과 출처 연결이 있는 자료는 출처에 귀속한 설명으로 활용하고, 한계와 검토 사항을 함께 전달합니다. URL이나 제목만으로 내용을 추측하지 않으며, 보고서 참고문헌에는 실제 본문에서 인용한 자료만 남깁니다.
