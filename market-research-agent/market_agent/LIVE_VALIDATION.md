## 발견한 문제와 수정

1. 검색어에 일반적인 `product deployment official`을 함께 붙이자 HW 검색에 위키백과의 제품 정의, CPSC, Energy Star 자료가 유입됐다. 짧은 기술 중심 질의로 변경했다.
2. 제목·검색 발췌에 기술명, KV cache, CXL 또는 추론 인프라 관련 단서가 없는 후보를 원문 조회 전에 제외한다. 후보 선택 여부와 이유를 로그에 남긴다. 이 최소 필터는 관련성의 완전한 판별기는 아니다.
3. 미확인 평가가 `unknown` 한 단어로 출력되면 해당 항목의 정보 공백을 한국어 문장으로 표시한다.
4. 프롬프트에서 기술 자체와 기술군의 근거를 구분해 활용하고, 입력 요약 기반 고객 가치는 조건부 추론으로 작성하도록 구체화했다.

## 확인한 오류와 수정

1. **약어 혼동:** RDKV TV/셋톱박스 개발 자료와 프로필이 이름 일치로 통과했다. 최초 질의에 `KV cache`를 명시하고 동명 자료에 LLM·양자화·KV cache 문맥이 있는지 검사한다.
2. **출력 필드 누락:** SDK가 전송하는 strict schema는 필수 필드를 포함한다. 다만 로컬 Pydantic 모델에는 구형 기록 읽기용 기본값이 있어, API 응답이 필드를 누락해도 빈 인용으로 파싱되는 경로를 합성 응답으로 재현했다. 모델 경계에서 verdict/citations/context_findings의 실제 반환 여부를 별도로 검사한다. 이 누락이 첫 라이브 실행의 유일한 원인이었다고 확정하지 않는다. 이후 실행의 검사 기록에는 필드 누락이 없다.
3. **과거 상태 누적:** 보완 후 원문을 검토했어도 이전 ‘미조사’ 문장이 남았다. 코드가 생성한 조사 사유는 회차마다 다시 계산한다.
4. **요약·웹의 범위 혼합:** 입력 요약 한 건이 논문 이름을 포함한다는 이유로, 함께 인용한 다른 제품의 웹 주장까지 exact로 인정할 수 있었다. 각 인용의 대상 연결을 검사하고, 전달받은 요약은 비용·가치의 조건부 추론에만 허용한다.
5. **잘못된 ID:** 최종 모델은 Marvell 발표 문구를 `E-HW-001` 입력 요약 ID로 인용했다. 그 영문 문구는 입력 요약에 없고 확보한 Marvell 발표 원문에 있었다. 보조 정보에 한해 실제 문구·대상 이름·동일성 문구를 대조하고, 같은 제목의 원문에서만 기존 웹 ID로 연결한다. 주장이 다른 문서에 모호하게 일치하면 교정하지 않는다.

# 근거 분리 v1.1 구현·검증 — 2026-09-22

## 코드 변경
