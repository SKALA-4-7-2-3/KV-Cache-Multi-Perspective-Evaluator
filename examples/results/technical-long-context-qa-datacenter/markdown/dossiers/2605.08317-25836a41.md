### 초록

Large language models (LLMs) have shown strong performance across diverse
tasks, but their inference with long input contexts is bottlenecked by memory size
and bandwidth. The Key-Value (KV) cache size grows linearly with sequence
length and needs to be re-read from off-chip high-bandwidth memory (HBM) to
on-chip memory at every decoding step, resulting in memory-bound inference.
Existing methods reduce the cache by either eviction or quantization, but typically
treat the two in isolation. In this paper, we cast KV cache compression as a rate-
distortion problem, under which eviction and quantization are two end-points of
the same bit allocation scheme. This exposes the need to optimize them jointly,
motivating our method, RDKV (Rate-Distortion KV cache compression). RDKV
derives the weight of each token or channel from the distortion that compression
induces on the attention computation. Based on these weights, it assigns each token
or channel a bit-width ranging from full precision down to zero bits guided by
reverse water-filling, applied once after the prefilling stage. Experiments on Long-
Bench, RULER, and InfiniteBench show that RDKV outperforms the best evaluated
baseline by 9.1% on average. On LongBench it recovers 97.81% of full-cache accu-
racy with only 2.48% cache retention. Compared with full-cache FlashAttention-2
decoding, it achieves 4.5× decode speedup and 1.9× peak memory reduction with
128K context length, while maintaining comparable performance.

## 기술 개요

### 문제 정의

- 장문맥 LLM 추론에서 KV cache는 시퀀스 길이에 선형 비례해 증가하며, 매 decoding step마다 off-chip HBM에서 on-chip memory로 재읽혀 memory-bound inference를 유발한다.
  - `author_claim` · confidence `0.990` · [ev-004](../evidence_registry.md#ev-004)
- 기존 KV cache 축소 방법은 eviction 또는 quantization을 대체로 분리하여 취급한다.
  - `author_claim` · confidence `0.980` · [ev-004](../evidence_registry.md#ev-004)

### 핵심 접근법

- RDKV는 고정 bit budget에서 V cache의 token과 K cache의 channel마다 bit-width를 배정하여 weighted distortion을 최소화하는 rate–distortion KV cache compression 방법이다.
  - `author_claim` · confidence `0.990` · [ev-003](../evidence_registry.md#ev-003)
- RDKV는 eviction을 zero-bit allocation, quantization을 finite-bit allocation으로 같은 allocation curve의 양 끝점으로 두어 공동 최적화한다.
  - `author_claim` · confidence `0.990` · [ev-003](../evidence_registry.md#ev-003)

### 신규성

- 논문은 continuous optimum이 zero-rate와 finite-rate unit을 혼합한다고 정식화하고, hardware-supported bit-width에 대한 discrete knapsack을 Lagrangian relaxation 기반 reverse water-filling으로 풀며, TriZone packed-decode layout으로 mixed-bit allocation을 실제 메모리 절감으로 전환한다고 제시한다.
  - `author_claim` · confidence `0.990` · [ev-003](../evidence_registry.md#ev-003)

### 메커니즘·알고리즘·수식

- V token weight는 w_t=Σ_τa_{τ,t}이고, K channel weight는 w_c=||Q_{:,c}||₂||K_{:,c}||₂/√d이다.
  - `author_claim` · confidence `0.990` · [ev-025](../evidence_registry.md#ev-025)
- 각 KV head에서 MCKP/reverse water-filling은 bit-width 집합 {0, 2, 4, 8, 16}으로 V token을 먼저 allocation하고, bit-width가 0보다 큰 retained token에 대해서만 K channel을 allocation한다.
  - `author_claim` · confidence `0.990` · [ev-001](../evidence_registry.md#ev-001)
- TriZone packing은 V sub-segment와 retained K row를 quantize·byte-pack해 Zone A에 두고, 16-bit V row는 FP16으로 Zone B에 저장한다.
  - `author_claim` · confidence `0.990` · [ev-001](../evidence_registry.md#ev-001)
- TriZone의 packed-decode layout은 dequantization을 attention kernel에 fuse한다.
  - `author_claim` · confidence `0.990` · [ev-003](../evidence_registry.md#ev-003)

### 학습 과정

- RDKV는 model weights 또는 training procedure를 수정하지 않는 inference-time KV cache compression 방법이다.
  - `author_claim` · confidence `0.990` · [ev-007](../evidence_registry.md#ev-007)

### 추론 과정

- RDKV는 prefilling stage 직후 한 번 allocation을 적용하며, Algorithm 1의 입력은 layer별 prefill KV cache, per-head budget Bhead, observation window Sw, pooling kernel w, bit-width set, empirical distortion table εK(b) 및 εV(b)이다.
  - `author_claim` · confidence `0.990` · [ev-001](../evidence_registry.md#ev-001)

### 입력·출력·데이터·연산 요구사항

## 한계

### 저자가 명시한 한계

- RDKV는 prefill 후 KV cache를 한 번만 압축하고 decoding 중에는 재평가하지 않으므로, allocation은 generation 중 발생할 수 있는 attention-pattern shift에 대해 고정된다.
  - `author_claim` · confidence `0.990` · [ev-007](../evidence_registry.md#ev-007)
- 저자들은 decode phase에 rate-distortion framework를 확장하는 것을 future work로 제시했으며, 최근 decode token의 작은 buffer에 attention weight를 누적하고 주기적으로 MCKP allocation을 적용하는 방안을 제안한다.
  - `author_claim` · confidence `0.980` · [ev-007](../evidence_registry.md#ev-007)
- Needle-in-a-Haystack 추가 실험에서 RDKV의 잔여 miss는 FullKV 자체가 recall을 잃기 시작하는 depth와 length에 집중된다고 저자들이 보고한다.
  - `author_claim` · confidence `0.940` · [ev-016](../evidence_registry.md#ev-016)

### 실험·가정으로부터 추론한 한계

- 따라서 긴 generation에서 attention pattern이 prefill 때와 달라지는 경우, 현재의 정적 allocation이 계속 적절하다는 실증 검증은 제시되지 않았다.
  - `analyst_inference` · confidence `0.880` · [ev-007](../evidence_registry.md#ev-007)

### 계산 제약

- LLaMA-3.1-8B-Instruct, 128K context length, A100 64 GB 조건에서 Table 12는 RDKV의 Net RDKV overhead를 FullKV prefill 대비 +1,740 ms 및 +6.0%로 보고한다.

- 같은 Table 12 조건에서 RDKV TTFT는 30,583 ms이며 FullKV prefill baseline의 106.0%로 보고된다.
